Jalaram Metals website redesign
================================

Static website built with HTML, CSS and JavaScript only (no React and no build step).
Open index.html directly, or use a local static server.

Pages: index.html, profile.html, products.html, contact.html, inquiry.html
Assets: the supplied brass slide photo, catalogue cover, and brass component illustration.

The homepage paragraphs visible in the provided reference screenshot are retained.
The supplied brass slide image and catalogue cover remain included and displayed.
Only one original carousel photo was present in the project files, so the eight
carousel controls cannot show eight distinct original photographs.

The contact and inquiry forms are front-end demos. They do not send information
to the company because no verified company submission endpoint was provided.
